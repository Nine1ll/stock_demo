용어/산식 설명

앱에서 보이는 지표가 무엇을 의미하고, 어떤 규칙으로 점수화되는지 정리한 문서입니다.

1. 핵심 용어

용어 의미 해석 팁
종합점수(Undervalued Rank) 밸류/품질/기술력/시장영향/과열을 합성한 0~100 점수 같은 섹터 내 상대순위와 함께 보는 것이 좋음
밸류(Valuation) PER/PBR과 품질/과열을 반영한 가격 매력도 점수 높을수록 상대 저평가 가능성
품질(Quality) ROE, 영업마진, 밸류 건전성, 변동성, 시총 안정성 반영 높을수록 펀더멘털 체력 우수
기술력(Tech Strength / Moat) 기술자료/공시/뉴스 신호와 테마 적합도를 반영 높을수록 기술/사업 연결 강함
자본력(Capital Power) 시가총액, 부채비율, 유동성(cash ratio) 기반 재무 체력 낮으면 변동장 방어력 약화 가능
시장영향(Market Impact) 시총, 뉴스 밀도, 가격 모멘텀 기반 시장 주목도 높아도 과열이 높으면 추격매수 주의
과열(Hype) 급등률/고평가 배수/뉴스 과다 노출 기반 과열도 높을수록 단기 변동성 리스크 증가
섹터열기(Heat) 최근 수급·뉴스·가격 탄력 기반 섹터 온도 높고 체력이 낮으면 동반급등 함정 가능
체력(Resilience) 품질+자본력+밸류를 과열 패널티로 보정한 내구성 높을수록 추세 지속/회복력 기대
시그널 상승 우세 / 중립 / 하락 우세 단기/중기/장기 시그널을 함께 확인

2. 주요 산식

2-1. 종합점수(Undervalued Rank)

rank = 0.27*quality + 0.25*tech_strength + 0.24*market_impact + 0.24*valuation - 0.10*hype

모든 점수는 0~100으로 클램프됩니다.

2-2. 밸류 점수(Valuation)

  • PER 낮을수록 가점, 과도하게 높으면 감점
  • PBR 낮을수록 가점, 과도하게 높으면 감점
  • 품질 점수 높으면 가점
  • 과열 점수 높으면 감점

2-3. 품질 점수(Quality)

  • ROE, 영업마진, 합리적 PER/PBR, 낮은 급변동, 충분한 시총에 가중치 부여
  • 수익성/안정성 훼손 시 감점

2-4. 과열 점수(Hype)

  • 최근 급등률, 높은 멀티플, 뉴스 과밀도(건수) 반영
  • 테마 과열 국면 식별에 사용

2-5. 섹터열기/체력 분리 지표

heat_score: 최근 등락, 뉴스량, 과열도 중심

resilience_score: quality/capital_power/valuation - 과열 패널티

  • heat↑ + resilience↓: 테마동반급등(체력취약)
  • heat↑ + resilience↑: 섹터상승+체력동반(추세지속후보)
  • heat 보통 + resilience↑: 저평가 체력 우위

3. 백테스트(리플레이) 지표 해석

지표 의미 활용
5일 백테스트 평균 해당 라벨이 발생한 시점 이후 5영업일 평균 수익률 신호 품질의 평균 성능 확인
승률(Hit Rate) 5영업일 후 수익률이 0% 초과인 비율 신호의 재현성 점검
5일 알파 해당 라벨 평균 수익률 - 전체 기준선 평균 수익률 시장 평균 대비 초과성과 판단

4. 해석 가이드(실무형)

  • 종합점수 단독보다 섹터열기 + 체력 + 리스크를 함께 보세요.
  • 상승 우세여도 과열이 높고 체력이 낮으면 분할/보수 접근이 유리합니다.
  • 체력이 높고 밸류가 양호한 종목은 눌림 시나리오에서 우선 검토하세요.
  • 동일 섹터 비교표에서 5일 알파가 양수인 종목을 우선 후보로 좁히세요.

  • 본 점수는 의사결정 보조용이며 투자 자문이 아닙니다.
  • 외부 API 지연/누락에 따라 일부 지표가 일시 왜곡될 수 있습니다.
  • 백테스트는 가격/거래량 프록시 기반 MVP로, 향후 시점정합 펀더멘털 결합이 필요합니다.
